Smart Token & Queue Management System for Agricultural Procurement

Eliminating 12–48 hour mandi queue delays using a dynamic slot allocation algorithm, offline-resilient microservices, and multi-channel access (PWA, IVR, WhatsApp, SMS).

The Problem

Farmers face long waiting times (12–48 hours) outside Mandis, lack of real-time info on procurement schedules, high crop spoilage risks due to open weather, and payment status uncertainties.

The Hexa Core Solution

An end-to-end cloud-native platform featuring automated slot dynamic scheduling, geofenced queue activation within a 2 km radius, Aadhaar e-KYC integration, and direct PFMS payment tracking.

Dynamic Allocation

Schedules tokens based on daily weighbridge and storage throughput.

Multi-Channel Access

Supports PWA, IVR toll-free voice calls, USSD code (*123#), and WhatsApp.

GPS Geofenced Queue

Tokens activate live only when farmer enters a 2 km perimeter.

DBT & PFMS Sync

Aadhaar e-KYC and Direct Benefit Transfer status updates via SMS.

Architecture & Technical Stack

Frontend Layer

Next.js / React PWA, Tailwind CSS for low-bandwidth UI styling.

Backend Microservices

Node.js (Express) / Python (FastAPI) cloud-native services.

Real-Time Sync

Socket.io and Redis cache for live queue display updates.

Geo-Spatial Database

PostgreSQL + PostGIS for 2 km boundary tracking.

Telecom & Gateways

Twilio / Gupshup APIs for SMS, WhatsApp Bot, and local IVRS calls.

Government Integrations

Aadhaar e-KYC, Land Record DB, and PFMS for DBT tracking.

Methodology & Implementation Flow

Phase 1
Initiation & Assessment: Problem Statement 26032 analysis, DOCA/Farmer stakeholder metrics definition.
Phase 2
Agile Platform Development: 2-week sprints, PWA/IVR design, microservices, dynamic slot allocation engine.
Phase 3
Integration & Security: Aadhaar e-KYC cross-verification, PFMS DBT integration, security vulnerability audits.
Phase 4
Pilot Deployment: High & low tech zone mandis, tablet deployment, staff/volunteer training.
Phase 5
Scale & CI/CD Pipeline: Feedback loop, state-to-national progressive rollout, automated CI/CD deployment.

Direct Benefits & Social Impact

Wait Time Reduction

Dramatically decreases mandi queues from 12–48 hours down to 1–2 hours.

Minimised Spoilage

Prevents post-harvest crop loss caused by unseasonal rain while waiting in open lines.

Price & Payment Transparency

Automated updates for moisture test scores and direct benefit transfer (DBT) milestones.

Future Business & Expansion Plan

Commercialization for private agribusinesses, food processors, and contract farming companies to manage private procurement hubs.

Logistics Aggregation
